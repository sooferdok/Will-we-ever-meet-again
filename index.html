왜 불가능할까? — 수식으로 증명

결론: 초기속도 벡터가 다르면 출발 후 같은 시각에 같은 위치에 도달할 수 없습니다. ‘초기속력’은 속도의 크기이고, ‘초기속도 벡터’에는 방향까지 포함됩니다.

두 물체의 출발 위치를 (x₀, y₀), 초기속력을 v₁, v₂, 수평선 기준 발사각을 θ₁, θ₂라고 합시다. 공기 저항 없이 동일한 중력가속도 g를 받으면

xᵢ(t) = x₀ + vᵢ cos θᵢ · t
yᵢ(t) = y₀ + vᵢ sin θᵢ · t − ½gt²   (i = 1, 2)

출발 후 어떤 같은 시각 T > 0에 두 위치가 같다고 가정하고, 두 물체의 식을 빼면 공통 출발 위치와 중력 항이 사라집니다.

0 = (v₁ cos θ₁ − v₂ cos θ₂)T
0 = (v₁ sin θ₁ − v₂ sin θ₂)T

T > 0이므로 T로 나눌 수 있습니다. 따라서 수평·수직 초기속도가 각각 같아야 합니다.

v₁ cos θ₁ = v₂ cos θ₂
v₁ sin θ₁ = v₂ sin θ₂
⇒ v₁² = v₂² ⇒ v₁ = v₂
⇒ θ₁ = θ₂   (0° < θ < 90°)

같은 시각에 같은 위치에 도착하려면 초기속력과 발사각이 모두 같아야 합니다. 두 조건이 같으면 궤적 전체도 같습니다. 그러므로 선생님이 제시한 ‘서로 다른 초기속력과 발사각’ 조건으로는 불가능합니다.

이 증명은 도착점의 높이가 출발점과 달라도 성립합니다. 같은 출발점·같은 출발 시각·같은 중력가속도라는 조건만 필요합니다. 물체의 질량이나 그림 크기는 이 이상적 운동식에 영향을 주지 않습니다.

상대운동으로 한 줄에 보기

r₂(t) − r₁(t) = (v⃗₂₀ − v⃗₁₀)t

두 물체가 같은 중력을 받으므로 상대가속도는 0입니다. 초기속도 벡터가 다르면 t > 0에서 상대위치가 0이 될 수 없습니다. 유한한 시뮬레이션 사례는 이 결론을 시각적으로 확인하며, 모든 발사 조건에 대한 불가능성은 수식이 증명합니다.

수업에서 확인할 세 가지 실험

먼저 예시 버튼을 누르고 ‘동시 발사’를 선택하세요. 일시정지하거나 시간 막대를 움직여 위치를 확인할 수 있습니다. 조건을 바꾸면 시간은 0으로 돌아갑니다.

  1. 도착 위치만 같게: 블루 20 m/s·30°, 테렌스 약 18.612097 m/s·45°. 두 속력과 각이 모두 다르며, 도착 위치는 약 35.348 m로 같습니다. 도착 시간은 약 2.041 s와 2.686 s로 다릅니다.
  2. 도착 시간만 같게: 블루 20 m/s·30°, 테렌스 약 14.142136 m/s·45°. 도착 시간은 약 2.041 s로 같습니다. 도착 위치는 약 35.348 m와 20.408 m로 다릅니다.
  3. 둘 다 같게: 두 물체 모두 20 m/s·45°. 도착 위치와 시간이 모두 같지만, 초기속력과 발사각도 같아집니다. 이는 ‘서로 다른 조건’에 대한 반례가 아닙니다.

같은 높이로 돌아올 때의 도착 시간과 수평 도달거리는 다음과 같습니다.

T = 2v sin θ / g
R = v cos θ · T = v² sin(2θ) / g

첫 번째 예시에서는 v₂ = √(20² sin 60° / sin 90°), 두 번째 예시에서는 v₂ = 20 sin 30° / sin 45°를 사용합니다. 예시 버튼은 반올림 전 값을 계산에 사용합니다. 입력칸에 표시된 근삿값을 다시 입력하면 아주 작은 차이가 생길 수 있습니다.

탐구 결론에 포함할 내용: 질문 → 공기 저항을 무시한 모델 → 운동방정식에 의한 증명 → 세 가지 시뮬레이션 결과 → 모델의 적용 범위.

파일로 보관하고 GitHub·Google Sites에 게시하기

아래 버튼은 이미지와 계산 코드가 모두 들어 있는 index.html 한 파일을 내려받습니다. 다운로드 후 브라우저로 열면 인터넷 없이도 작동합니다.

GitHub Pages

  1. GitHub에 로그인하고 새 저장소(New repository)를 만듭니다. 이름은 projectile-lab, 공개 범위는 Public으로 설정합니다.
  2. 저장소에서 Add file → Upload files를 선택합니다. 빈 저장소에서는 ‘uploading an existing file’을 선택할 수도 있습니다.
  3. 내려받은 index.html을 업로드하고 Commit changes를 누릅니다. 파일은 폴더 안이 아닌 저장소의 맨 위에 둡니다.
  4. Settings → Pages → Build and deployment로 이동합니다.
  5. Source를 Deploy from a branch, Branch를 main, 폴더를 / (root)로 지정하고 Save를 누릅니다.
  6. 게시가 끝나면 Pages에 표시되는 주소를 엽니다. 일반적으로 https://아이디.github.io/projectile-lab/ 형태입니다. 선생님께 이 주소를 보내세요.

파일 이름은 소문자 index.html이어야 합니다. 저장소 파일 주소(github.com)와 실제 웹페이지 주소(github.io)는 다릅니다.

Google Sites에 넣기

  1. 위 순서로 GitHub Pages 웹페이지를 먼저 게시합니다.
  2. Google Sites에서 사이트를 만들고 삽입 → 삽입(Embed) → URL에 GitHub Pages 주소를 붙여 넣습니다.
  3. 시뮬레이션이 충분히 보이도록 삽입 영역의 높이와 너비를 늘립니다.
  4. 게시를 누르고 선생님이 볼 수 있는 공개 범위를 선택한 뒤 게시된 Google Sites 주소를 보냅니다. 학교 계정은 학교의 공유 설정에 따라 외부 접근이 제한될 수 있습니다.
